# Employee Performance & HR Analytics Dashboard

## Project Overview

This project builds an Employee Performance and HR Analytics Dashboard using Python and Streamlit. The dashboard reviews employee attrition, salary patterns, performance ratings, overtime, job roles, and years at the company.

The goal of this project is to show how HR data can be cleaned, analyzed, and displayed in a simple dashboard to support business decision-making.

The main dataset is the IBM HR Analytics Employee Attrition & Performance dataset from Kaggle. This dataset includes employee attrition, department, monthly income, performance rating, job role, age, gender, overtime, and years at the company.
